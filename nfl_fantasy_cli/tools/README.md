# Tools Directory

This directory contains various tools and utilities for the NFL Fantasy League CLI.

## Structure

- **`analysis/`** - JSON structure analysis tools
- **`integration/`** - Data integration and parsing tools  
- **`demos/`** - Demonstration scripts and examples

## Usage

Each subdirectory contains specific tools for different aspects of the fantasy league system.

### Analysis Tools
Tools for analyzing NFL API JSON responses and understanding data structures.

### Integration Tools
Tools for integrating real NFL API data into the fantasy league system.

### Demo Tools
Demonstration scripts showing how to use the various tools and APIs.
