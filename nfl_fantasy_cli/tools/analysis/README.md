# Analysis Tools

This directory contains tools for analyzing NFL API JSON responses and understanding data structures.

## Files

- **`analyze_json_structure.py`** - Initial JSON structure analyzer
- **`analyze_json_structure_fixed.py`** - Fixed version with proper error handling

## Usage

```bash
# Run the fixed analyzer
python3 analyze_json_structure_fixed.py
```

## Purpose

These tools help understand the structure of NFL API responses so we can create proper parsers for the fantasy league system.
